## Overview

Read-across is a powerful tool for filling toxicological data gaps, particularly for chemicals where traditional testing is not feasible, economically viable, or ethically acceptable. This page explores the strategies, approaches, and best practices for using read-across to address data gaps in chemical safety assessment.

## Scope and Notes

This page focuses on the application of read-across specifically for data gap filling. It covers the identification of data gaps, selection of appropriate read-across strategies, implementation of data filling approaches, and evaluation of the filled data quality.

## Key Definitions and Claims

> **Claim**: Read-across is seen as a possible way to fill gaps in toxicological data for substances where testing is not feasible or economically viable.

- Mutagenicity
- Reproductive toxicity
- Developmental toxicity
- Neurotoxicity
- Immunotoxicity
- Endocrine disruption

**Physicochemical Properties**:

**Toxicokinetic Data**:
- Absorption
- Distribution
- Metabolism
- Excretion (ADME)

**Exposure Data**:

- Consumer exposure
- Occupational exposure
- Biomonitoring data

### Gap Identification Process

1. **Regulatory Requirements Review**:
   - Identify data requirements for specific regulatory frameworks
   - Review information requirements for target chemical
   - Determine compliance status

2. **Existing Data Assessment**:
   - Inventory available data for target chemical
   - Evaluate data quality and relevance
   - Identify specific gaps

3. **Priority Setting**:
   - Rank gaps by regulatory importance
   - Consider data availability for potential sources
   - Assess feasibility of read-across approaches

## Read-Across Strategies for Data Gap Filling

### Method Selection

**Analogue Approach**:
- Best for specific endpoint predictions
- Requires close chemical similarity
- Needs detailed source chemical data
- Suitable for targeted data gaps

**Category Approach**:
- Best for hazard classification
- Requires broader chemical categories
- Benefits from multiple source chemicals
- Suitable for multiple endpoint gaps

### Strategy Selection Criteria

- **Gap Type**: Nature and specificity of the data gap
- **Chemical Similarity**: Availability of similar chemicals
- **Data Availability**: Quality and quantity of source data
- **Regulatory Context**: Framework-specific requirements
- **Resource Constraints**: Time and budget considerations

## Implementation Approaches

### Step-by-Step Data Filling Process

1. **Source Identification**:
   - Identify potential source chemicals
   - Apply similarity criteria
   - Review data availability

2. **Similarity Assessment**:
   - Conduct structural similarity analysis
   - Evaluate mechanistic similarity
   - Compare physicochemical properties
   - Assess toxicokinetic similarity

3. **Data Transfer**:
   - Select appropriate data points
   - Apply transfer methodology
   - Consider endpoint-specific requirements
   - Document transfer rationale

4. **Uncertainty Assessment**:
   - Identify sources of uncertainty
   - Assess uncertainty magnitude
   - Apply uncertainty factors
   - Characterize remaining uncertainty

5. **Data Integration**:
   - Combine filled data with existing data
   - Ensure consistency across data streams
   - Address potential conflicts
   - Document integration process

### Endpoint-Specific Approaches

**Acute Toxicity**:
- LD50 estimation from similar chemicals
- Dose-response curve extrapolation
- Mechanism-based predictions

**Chronic Toxicity**:
- NOAEL/BMD extrapolation
- Carcinogenicity risk assessment
- Chronic exposure modeling

**Reproductive/Developmental Toxicity**:
- Developmental endpoint predictions
- Reproductive parameter estimation
- Critical window identification

**Genotoxicity**:
- Ames test result extrapolation
- Mutagenicity prediction
- Carcinogenicity risk assessment
